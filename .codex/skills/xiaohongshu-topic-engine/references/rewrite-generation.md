# Differentiated rewrite

Use only with source content the user is allowed to adapt.

1. Decompose the source into 4–6 modules, each with a name, narrative role, and transferable element.
2. Explain its attention mechanism: emotional trigger, information gap, framing, rhythm, or structure.
3. Retain only abstract structure and broad tone; replace audience, scenario, examples, and wording with new material.
4. State each rewrite's audience and `angle_shift` so differentiation can be inspected.
5. Include a safety assessment for each output.

Do not imitate distinctive sentences, punchlines, personal anecdotes, or identifying details. If an output would be too close, choose a new angle and structure.
